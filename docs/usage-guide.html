Hermes Box Lite

A practical guide to creating, using, backing up, restoring, and repairing isolated agent boxes.

i
The operating model

Tools are replaceable; state is precious. Claude Code, Codex, Hermes, Executor, and Neovim live in an isolated smolvm VM. User state lives under /data and travels through encrypted backups.

Quick start

Run these commands from the hermes-box-lite repository on macOS, or on x86_64/arm64 Linux with KVM available and your user allowed to access /dev/kvm. Install smolvm, GPG, curl, jq, tar, awk, and standard Bash command-line tools first.

On Linux, verify virtualization access before creating a box:

test -r /dev/kvm -a -w /dev/kvm
smolvm machine ls

1. Create and verify a box

./box new alpha
./box doctor alpha

Creation boots Ubuntu with configurable CPU, memory, and a 64 GiB default overlay, installs the toolchain and a full-SHA-pinned Hermes checkout, starts Executor, registers its authenticated HTTP MCP endpoint with Claude and Codex, and runs health checks. Hermes begins durably disabled until setup or a migration cutover is complete.

2. Enter and authenticate

./box enter alpha

You enter as agent in a persistent tmux session under ~/workspace. Authenticate the tools you intend to use:

hermes setup --portal
claude
codex

3. Open Executor and save the state

./box open alpha
./box save alpha

box open waits for the authenticated forwarded endpoint, then launches the Executor UI without printing its bearer token. box save quiesces Hermes and Executor, checkpoints and verifies SQLite, excludes transient/native caches and locks, validates and encrypts the archive, then selectively restores the prior service state.

The workload supervises Executor and the Hermes gateway without duplicate processes. Doctor is read-only and treats deliberate quiescence as policy, while start and repair remain explicit mutations. Gateway enable requires the full single-writer confirmation phrase printed by hb gateway-enable.

Backup and restore

Create a backup

./box save alpha

By default, this creates backups/alpha-<timestamp>.tar.gz.gpg. The command refuses to overwrite an existing destination. Set a passphrase in the environment for unattended use:

BOX_PASSPHRASE='your-local-secret' ./box save alpha

The mode-0600 runtime manifest is atomically published at ~/.config/hermes-box/runtime-manifest. Hermes and Executor are stopped, every Hermes SQLite checkpoint is confirmed non-busy and integrity-checked, and transient caches, native dependency trees, Hermes sidecars, PIDs, and locks are excluded. Unrelated database sidecars elsewhere under /data are preserved.

Restore into a new box

./box load backups/alpha-20260625-120000.tar.gz.gpg beta

The archive is decrypted and validated before a VM is created. The destination is provisioned, extracted into staging while services are quiesced, SQLite-verified before the state swap, refreshed, rewired, and health-checked. The Hermes gateway remains disabled so restore rehearsals cannot claim a live messaging identity.

Import from Eventide or another Hermes host

./box import-hermes alpha hermes-backup.zip --map /Users/davis=/data/home/agent

Native import rejects traversal and symlink entries before guest mutation, stages and atomically swaps ~/.hermes, rewrites only active config, env, cron, hook, and script files, and leaves historical sessions, memories, databases, and logs byte-for-byte unchanged. External provider destinations are previewed and require --include-external. Review the manifest, run hb acknowledge-active-paths, then require hb cutover-ready before enabling the gateway.

Inspect a backup without a VM

./box extract backups/alpha-20260625-120000.tar.gz.gpg

Extraction validates the archive and writes to a new directory under backups/. Treat extracted contents as sensitive: they can contain credentials, sessions, private work, and Executor data.

!
Backups preserve state, not an exact machine

Hermes is pinned by full Git SHA and can be seeded from an ignored local Git bundle for a custom Eventide commit. Other OS and tool packages can still drift; this remains a state backup, not an offline VM image.

Health and repair

Start with the doctor whenever a box feels partly broken:

./box doctor alpha

Doctor performs a bounded, authenticated MCP handshake through the guest-local endpoint and, when web exposure is enabled, the forwarded host endpoint. It uses jq to validate the HTTP 200 JSON initialize result, negotiated protocol version, response content type, and session ID, sends the initialized notification, then closes the session best-effort. A bare listener, malformed result, 404, or HTTP 500 response fails health. Without an exposed port, doctor reports the host check as skipped.

If managed tools, profiles, or MCP wiring need repair, re-run provisioning:

./box repair alpha

Repair quiesces Hermes and Executor, refreshes packages and repository-owned guest assets, checks out the configured Hermes SHA exactly, resumes the prior service policy, repairs MCP wiring, and runs the doctor.

Remove a box safely

./box rm alpha

The command reports whether it can find a recent backup and requires the exact box name as confirmation. For intentional non-interactive deletion:

./box rm alpha --force

Provisioning installs a root-owned copy at /etc/hermes-box.env, so guest helpers use the same settings as the host workflow.

Security model

  • The VM has no host filesystem mounts.
  • Executor's forwarded web port is host-loopback-only.
  • Hermes API forwarding is disabled by default and host-loopback-only when enabled.
  • Networking is always enabled for provisioning and agent tools.
  • Claude, Codex, Hermes, Executor, and plugins share one guest account and credential set.
  • The agent user has passwordless sudo inside the guest.
  • Encrypted backups and extracted state should be handled as secret material.

The VM is the host-protection boundary. Tools inside a box are not isolated from one another. A compromised tool, plugin, MCP source, or prompt-injected agent may access the other tools' credentials and workspace.

Troubleshooting

Executor or MCP is unhealthy

./box doctor alpha
./box repair alpha

Inside the box, inspect hb status and hb logs executor. Run hb wire-mcp to replace stale legacy stdio wiring with the authenticated HTTP configuration.

An operation says the box is locked

Another mutation may be running. Locks contain an owning PID and stale locks are recovered automatically after that process exits. Do not manually remove a lock while a save, load, repair, or delete is active.

A restore fails before VM creation

The passphrase may be incorrect, or the decrypted archive may be corrupt or unsafe. This failure intentionally occurs before provisioning so it does not leave an orphan VM.

Validate the repository

make check

This requires ShellCheck, Python 3, and jq, then runs Bash/Python syntax checks, static contracts, protocol-health regressions, encrypted archive round trips, native Hermes ZIP/import safety tests, validation-before-VM tests, cleanup checks, and mock failure rollback.
